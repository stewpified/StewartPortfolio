Hands-On Interaction & Cooking System

A hands-only interaction and inventory system built for a food-processing and cooking game — no menus, just picking up and moving food, tools, and dishes in real space.

Blueprints Interfaces Systems

In order to create a food processing and cooking system that felt hands-on and more real, I created an interaction and inventory system where the player holds items and tools in their hands only, skipping out on a standard inventory based on menus. Instead, the player must use their hands and move food, tools, etc. in real space.

The first foundational part of making this system work was getting the input actions system running and working alongside my player character blueprint so the player could interact with any object and the correct actions would pass through the actor that is interacted with. This was done through creating a blueprint interface for interactions as well as tool interactions, so if an object should react to a knife, but not your hands, it will respond accordingly.

image / video

The next task at hand is using data tables to create recipes and building each blueprint (like a stovetop or a rice cooker) so the player can actually cook and create dishes.
